# 效果目录 (Effects Catalog)

本文档是项目内**所有效果的唯一清单**：每个效果的编号、所属类别、描述、交互方式、技术路线和状态都以这里为准。
新增、调整或完成效果时，必须同步更新本文档（见 [CONVENTIONS.md](CONVENTIONS.md#文档维护)）。

## 状态说明

| 状态 | 含义 |
|---|---|
| `done` | 已实现，已上线展示页 |
| `wip` | 开发中 |
| `planned` | 已规划，未开始 |
| `idea` | 候选想法，尚未确认是否要做 |

## 批次说明

每章先做 3 个**精品首发**（批次 `1`），确认质量后再做**扩充**（批次 `2`）。Cyber 章的 6 个已完成效果计为首发批次。

## 编号规则

`<类别前缀>-<两位序号>`，例如 `PX-03`。编号一经分配不再复用；效果被废弃时把状态标为 `dropped`，不删除记录。

## 技术路线代号

| 代号 | 含义 |
|---|---|
| `shader` | 单个全屏片元着色器（WebGL2），基于共享的 `useShaderCanvas` |
| `three` | Three.js 场景（粒子、网格、自定义 ShaderMaterial） |
| `sim` | GPU 或 CPU 模拟（流体、元胞自动机、反应扩散等），通常需要多 pass / ping-pong |
| `canvas` | Canvas 2D 绘制 |
| `dom` | DOM + CSS（3D 变换、混合模式、可变字体等），不占用 WebGL 上下文 |
